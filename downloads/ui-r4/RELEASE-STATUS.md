검증 증거:
- g1-common-gui-stage1/2/3.log: 각 230개 GUI 확인, 실제 PDF·Excel·12개 DOCX 재열기, 원본 SHA256 보존.
- 각 캡처의 도면선 481픽셀·본문 163픽셀을 저장 PDF의 독립 렌더와 비교: 세 번 모두 평균 채널 오차 0.
- drawing-gui-stage1/2/3.log: 자체 도면 읽기 3회 회귀.
- ai-gui-stage1/2/3.log: 모의 로컬 AI 응답 연결 3회 회귀. 실제 모델 판독 PASS로 해석하지 않음.
- lunar-verification.log: 3회, 고정 명절/윤달 사례 9개·참조 데이터 비교 302개·잘못된 날짜 방어 6개씩 확인.
- 외부 셸의 드롭 전달을 대신하는 테스트 전용 DLL은 테스트 소유 AiPDF 프로세스 안에서 정상 HDROP을 생성합니다. 제품 EXE에 시험 훅은 없으며 실행용 ZIP에 이 DLL을 넣지 않습니다.

제한:
- 음력 표시 범위는 양력 2000~2050년, 표시 시간대는 KST입니다. 범위 밖은 임의 날짜를 만들지 않습니다.
- 한글 표시에는 운영체제의 사용 가능한 한글 글꼴이 필요합니다. Malgun Gothic/Noto Sans CJK KR 등 실제 설치된 글꼴을 선택합니다.
- PDF 스냅샷은 128MiB, 분리는 1~10000쪽 범위입니다. 지원하는 첫 줄 번호가 필요하며, 주석/양식·암호 문서는 무손실 처리 미구현 시 차단합니다.
- MuPDF 크로스 빌드에 SSE4.1 컴파일 옵션을 사용했습니다. 실제 대상 PC 호환성은 최종 Windows 시험 대상입니다.
- 기존 임의 DOCX의 복잡한 서식·이미지를 그대로 합치는 기능은 구현하지 않았습니다.

향후 최종 Windows 통합 시험 한 건:
실제 한글 경로 도면 PDF를 창에 드롭하고 회전 저장·분리·파일명변경까지 수행한 뒤, 공통 Excel 첫 열 번호를 다르게 바꿨을 때 메뉴 3이 잠기고 번호 복원 후 실제 재검사 PASS에서만 다시 활성화되는지 확인합니다.

상세 AI 사용 매뉴얼은 후속 수정 단계로 보류했습니다.
